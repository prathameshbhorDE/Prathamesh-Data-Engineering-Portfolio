# AWS Serverless Collateral Data Pipeline

## Overview
Production-style serverless data engineering pipeline built using AWS services to process collateral management data.

## Architecture
S3 → Lambda → Step Functions → Glue → Athena → SNS

## Services Used
- Amazon S3
- AWS Lambda
- AWS Glue
- AWS Athena
- AWS Step Functions
- Amazon SNS
- CloudWatch

## Features
- Automated validation
- Bronze/Silver/Gold architecture
- Data quality checks
- Athena analytics
- Email notifications

## Dataset
Synthetic collateral management dataset inspired by real-world fintech workflows.
